## 3. 审校提示（交给独立审校代理，例如 Claude）

```
请审校《高等工程数学》知识点讲解的以下文件：<文件路径列表>。
仓库根目录：/Users/edwinnull/Documents/高等工程数学习题解答。规范：.work/kp/SPEC.md（先通读 §2、§5、§6、§8、§11.3 与相关的 §12）。
教材是扫描版 PDF，页面图像在 /Users/edwinnull/Documents/.work/pages/book-NNN.png（PDF 页 = 书页 + 11），每节的阅读范围用 python3 .work/kp/tools/kp_tool.py pages <ID> 查看。

请逐项核查并报告：
1. 每一个定义、定理、推论、引理的陈述是否与教材页面一致（条件、结论、记号）；每一个编号、页码是否正确。
2. 数学推导的每一步是否正确；证明是否按 SPEC §6.5.5 的分级写足。
3. 重新运行 .work/kp/verify/<ID>.py，并独立复算 2–3 个关键数值。
4. 与对应习题解答是否一致（结论、方法、勘误处理）。
5. 是否有照抄教材的段落；拓展内容是否标注、是否正确。
6. 易错点、自测题、习题导航是否正确且有价值。
7. 运行 python3 .work/kp/tools/kp_tool.py check <ID>，报告结果。

输出：按严重程度排序的问题列表。每条包含：文件与行号、问题描述、教材依据（书页）、建议修改。严重程度分三级：
- 严重：数学错误、编号或陈述与教材不符、与习题解答矛盾；
- 一般：遗漏教材内容、证明或步骤不足、记号不一致、链接或格式问题；
- 建议：表达、组织、例题选择方面的改进。
只报告问题，不要修改文件。
```
