## 1. 项目概述

### 1.1 背景

本仓库已完成全书 33 个习题集、252 道题的完整解答（见 `README.md`），解答已逐题对照教材页图并用 Python 复算核对。本工程在此基础上，为教材正文的**每一节**编写知识点讲解，形成「部分—章—节」三级结构，与现有习题解答双向链接。

### 1.2 目标读者

使用本教材的工科研究生：学过本科线性代数、微积分、概率论与数理统计，目标是**理解概念、掌握方法、能独立完成本书习题并应对考试**。讲解默认读者手边有教材，但读者应能**只看讲解就理解本节全部要点**。

### 1.3 交付物

| 交付物 | 数量 | 位置 |
|---|---|---|
| 节讲解 | 70 | `<章目录>/知识点讲解/第x.y节_<标题>.md`（路径见 `sections.json`） |
| 章导读 | 17 | `<章目录>/知识点讲解/00_本章导读.md` |
| 部分导读 | 3 | `<部分目录>/00_<部分中文>导读.md` |
| 总目录 | 1 | 根目录 `知识点讲解总目录.md`（由工具 `index` 生成，不手写） |
| README 更新 | 1 处 | 根目录 `README.md`（阶段 3） |
| 习题解答回链 | 33 个文件各 1 行 | 由工具 `backlinks --apply` 写入（阶段 3），不手写 |
| 过程文件 | 每节 1 个清单 + 1 个验算脚本；第二、三部分每章 1 个习题分配表 | `.work/kp/` |

### 1.4 范围外（不要做）

- 不修改现有习题解答的正文（阶段 3 只由工具插入一行回链）。发现解答有错，登记 `ISSUES.md`，不自行修改。
- 不转录、不翻印教材：定义与定理可以忠实转述，证明、例题必须重新组织并加入讲解，不得整段照抄（§6.5.4）。
- v1 不配图、不写代码块、不写交互内容。
- 不新增题库：自测题每节 3–8 道，典型例题每节 2–4 道。
- 不写与本教材无关的专题（如数值线性代数的最新算法、贝叶斯统计等）。

### 1.5 总体验收标准

1. 70 节、17 章导读、3 部分导读全部存在，`kp_tool.py check all --strict` 零错误。
2. 每一个教材定义、定理、推论、引理都在对应节中按原编号讲到（工具按清单核对）。
3. 每一个被引用的编号都真实存在（工具按清单核对）；抽样人工核对无错误（§11.3）。
4. 每一个数值都可由 `verify/<ID>.py` 复现。
5. 与现有习题解答无矛盾；习题导航覆盖全部 252 题。

## 2. 红线（违反任一条，该节判为不合格，必须返工）

**R1 教材是唯一依据。** 每一个定义、定理、公式、例题、编号、页码、记号，都必须是执行代理**本次亲自阅读页面图像**后写下的，严禁凭记忆或凭“一般教材都这么写”。看不清就高清重渲染（§3.1），仍看不清就标【待核】并登记，不得猜。

**R2 编号零幻觉。** 正文中出现的每一个「定义 x.y-z」「定理 x.y-z」「式 (x.y-z)」「表 x.y-z」「x.y 节例 N」都必须登记在对应节的清单中（工具会核对）。查不到编号的内容，只描述内容、不写编号。

**R3 记号与教材一致。** 使用教材的记号和术语（如 $\mathrm{Sp}(\boldsymbol A)$、$\mathrm{Cond}(\boldsymbol A)$、Seidel 迭代法、盖氏圆、下侧分位数 $u_p$）。需要提及其他教材的写法时，用括注说明“其他教材常记作……”，正文仍用本书记号。

**R4 数值必验算。** 讲解中出现的每一个非平凡数值（包括小例、典型例题、自测题答案、表格中的数）都必须在 `verify/<ID>.py` 中用 Python 复算并 `assert`，脚本运行输出 `ALL OK`。

**R5 与现有习题解答一致。** 讲解中涉及习题的结论、方法、勘误处理必须与现有解答一致。若认为现有解答有误，**不得**在讲解中给出相反结论了事：先登记 `ISSUES.md`（类型“与解答冲突”），在讲解中只写确有把握的部分，并在回报中提出。

**R6 不省略。** 禁止「略」「证明略」「读者自证」「留作练习」「此处省略」等表述（工具会查）。教材自己写“请读者自证”的结论，讲解必须补出证明（至少关键步骤）。「显然」「易知」「不难」只有在紧跟一句理由时才能使用；引用块中忠实转述的教材原话可以保留这些词（工具不对引用块报警）。

**R7 不照抄。** 不得整段复制教材的叙述、证明或例题解答。定义、定理的陈述可以忠实转述（数学内容必须一致）；证明和例题要重新组织，补出教材跳过的步骤，并加上讲解。

**R8 拓展有界且标注。** 教材之外的内容只能放在「**拓展**」栏或明确标注“（教材未列）”，必须是标准、可验证的结论，每节拓展内容不超过全文的约 20%，不得与教材的约定冲突。

**R9 不确定就标记。** 拿不准的地方写【待核】并在 `ISSUES.md` 登记；一章完成前该章所有【待核】必须清零（解决或经项目所有者确认后删除）。

**R10 只改允许的文件。** 只新建、修改本工程的交付物与 `.work/kp/` 下由执行代理维护的文件。不改动现有习题解答、`.work/AGENT_BRIEF.md`、`.work/PAGE_INDEX.md`、`.work/legacy/`、PDF 与 `.DS_Store`。提交时逐个 `git add` 路径，**禁止** `git add -A` / `git add .`。

**R12 禁止批量生成。** 每一节都必须单独完成 §9.1 的全部步骤。禁止用脚本、模板或循环批量生成讲解正文、清单或验算脚本；禁止在不同节之间复用同一段套话。违反本条产出的文件一律视为占位稿，必须重写。

**R11 如实回报。** 回报中写清完成了什么、哪些检查通过、哪些警告保留及理由、有哪些未解决问题。不得把未运行的检查说成已通过。

## 5. 编号与引用体系

### 5.1 知识点 ID

`<部分字母><节号>.K<序号>`：`M`＝第一部分 矩阵论，`N`＝第二部分 数值计算方法，`S`＝第三部分 数理统计。例：`M3.3.K2` 是第一部分第 3.3 节的第 2 个知识点，`N4.2.K1`、`S3.2.K5` 同理。序号在本节内从 K1 起连续编号，跨小节不重新开始。

### 5.2 教材元素的引用格式

| 对象 | 写法 | 说明 |
|---|---|---|
| 定义、定理、推论、引理 | `定义 3.3-1`、`定理 4.1-2` | 与教材相同的“节号-序号”形式；类型词与编号之间一个半角空格 |
| 公式 | 正文写 `式 (3.3-1)`；重述带编号的教材公式时在行间公式内用 `\tag{3.3-1}` | 教材也有 `(3.2-9')` 这样的带撇编号，照写 |
| 表 | `表 4.1-1` | |
| 例题 | `3.3 节例 1`（本节内可简写 `例 1`，但跨节必须带节号） | **教材的例题按节编号**，各节都从例 1 开始 |
| 正文中的无编号例子 | `教材书页 89 正文例` | |
| 页码 | `书页 89`；需要时 `书页 89–91（PDF 100–102）` | 页码范围用短横线「–」 |
| 跨部分引用 | 在编号前加部分名：`第二部分定理 3.1-1`、`第一部分式 (3.2-6)` | 三个部分的章节号互相重复，跨部分不加前缀会指错 |
| 习题 | `习题 3.3 第 2 题`、`习题 6（第二部分）第 5 题` | |

### 5.3 已知编号陷阱

1. **三个部分章节号重复**：第一、二、三部分都有“2.1 节”“定理 2.1-1”。跨部分引用必须加部分名（§5.2）。
2. **例题按节编号**：书页 13 的“例 4”“例 5”属于 1.2 节，书页 351 的“例 5”属于第三部分 2.2 节。
3. **教材编号印刷错误**：如书页 88（第一部分 3.2 节）的定理印作“定理 2.3-2”，按所在小节与编号顺序应为“定理 3.2-2”（与第 2.3 节真正的定理 2.3-2 撞号）。处理：清单中按更正后的编号登记并加 `printed_as` 字段；讲解中写“定理 3.2-2（教材印作“定理 2.3-2”）”；在 `ISSUES.md` 登记。
4. **正文中引用的编号也可能印错**：如第三部分书页 327 写“与(2.1-4)式所给的样本方差 $S^2$ 略有不同”，而样本方差在同页式 (1.2-4) 给出。引用前核对被引对象。

二级标题只能是这 10 个，顺序固定，文字逐字一致。不得增加其他二级标题。

### 6.2 头部信息块

五个字段依次为 `**教材位置**`、`**对应习题**`、`**前置知识**`、`**后续应用**`、`**导航**`，每个字段一个引用段落，字段之间用只含 `>` 的空行隔开（否则部分渲染器会把它们并成一行）。

- **教材位置**：`书页 a–b（PDF c–d）`，取 `sections.json` 的 `read_book_pages` / `read_pdf_pages`，工具逐字核对。
- **对应习题**：第一部分写“共 N 题”；第二、三部分写“本节涉及第 x、y 题”（依据本章习题分配表）。
- **前置知识 / 后续应用**：各 1–4 个节级链接，只写**核实过**确有依赖的节（看过对方教材页或清单）。没有就写“无”并一句话说明。
- **导航**：本章导读、上一节、下一节（跨章时链接到相邻章的节；全书首末节写“无”）。

### 6.3 本节导读

- **这一节要回答的问题**：1–3 句，以问题形式给出动机。
- **学习目标**：3–6 条，用“会……”“能判断……”“能说明……”这类可检验的动词。
- **在全书中的位置**：承上启下，只写已核实的联系。
- **学习重点 / 难点**：难点要说明难在哪里。

### 6.4 知识结构

嵌套列表，每项是“知识点 ID　名称（教材元素）”，下级项说明与上级的逻辑关系（推出、特例、应用、对照）。末尾一句话概括本节主线。不得使用 Mermaid 等图表语法。

### 6.5 知识点讲解

#### 6.5.1 什么算一个知识点（粒度）

一个知识点是读者需要**单独掌握**的一个单元，通常是下列之一：

- 一个定义，或一组紧密相关、不可分开理解的定义（如“谱与谱半径”）；
- 一个主要定理连同它的推论；
- 一个方法或算法（如“列主元消去法”“求 Jordan 标准形的步骤”）；
- 一个重要公式族（如“三种诱导范数的计算公式”）；
- 教材用整段篇幅阐述的一个重要观察或反例（如“谱半径不是矩阵范数”）。

数量参考：教材 1–3 页的节 3–6 个；4–7 页 5–9 个；8–12 页 7–14 个；任何节不超过 16 个。知识点名称不超过 16 个汉字，用名词短语，**不含公式**。

#### 6.5.2 顺序与分组

- 知识点顺序跟随教材的叙述顺序；为讲清逻辑可以小幅调整，但须在“知识结构”中体现。
- 本节有小节（`sections.json` 的 `subsections` 非空）时：先写 `### x.y.z　小节标题`（与教材一致），其下知识点用 `####`；没有小节时知识点直接用 `###`。
- 教材在第一个小节标题之前已有正文（节首引言中的定义、记号、例子等）时，这部分内容**并入第一个小节**，作为该小节的开头知识点，并在“教材依据”中注明实际书页（如“书页 30–31，位于 1.5.1 小节标题之前”）。
- 教材定义、定理、推论、引理**一个都不能漏**（工具按清单核对）；教材例题至少要在某个知识点或典型例题中被提到（清单中 `kp` 或 `skip_reason` 二选一）。

#### 6.5.3 知识点块的固定栏目

每个知识点块由下列加粗标签引导，标签后接全角空格「　」。

| 栏目 | 是否必需 | 内容要求 |
|---|---|---|
| `**教材依据**` | 必需 | 教材元素编号 + 书页，如“定理 3.3-1、式 (3.3-1)（书页 89）”。方法类知识点写所依据的式号/算法所在书页 |
| 引用块（`>` 开头） | 定义、定理类必需 | 忠实转述教材的陈述：条件、结论、记号与教材一致 |
| `**理解**` | 与 `**要点**` 至少有一个，一般两者都要 | 直观解释：动机、几何/物理意义、“它在说什么” |
| `**要点**` | 同上 | 条件为什么不可少（尽量配反例）、适用范围、与相近概念的区别、常用变形、计算技巧 |
| `**证明思路**` | 有证明价值的定理 | 按 §6.5.5 分级处理 |
| `**例**` | 计算性知识点必需，其余建议 | 一个短例（≤15 行），可取教材正文例或自编；数字须验算 |
| `**易错**` | 可选 | 本知识点特有的错误 |
| `**拓展**` | 可选 | 教材以外的内容，受 R8 约束 |
| `**关联**` | 可选 | 指向其他知识点或其他节 |

每个知识点块一般 400–1500 字（含公式源码约 800–3500 字符）。

#### 6.5.4 转述的忠实性

1. 定义、定理的**条件与结论**必须与教材一致：不得加强结论、减弱条件或偷换记号。教材条件多余（如 3.3 节例 1 的“可逆”）时，先照录教材，再在要点中说明“该条件实际上不需要”并给出理由。
2. 教材表述有印刷错误、不严密之处：照录正确的数学内容，在要点中加括注说明（如样章 M3.3.K5 “教材此处写作等号……严格说是 ≤”），并在清单 `errata` 中登记；**明显的印刷错误**还要登记 `ISSUES.md`，由项目所有者决定是否进入 README 勘误表。
3. 转述的文字要用自己的话组织；可以保留教材中的关键术语与公式。

#### 6.5.5 证明的处理（分三级）

| 级别 | 适用 | 写法 |
|---|---|---|
| A：完整推导 | 教材给出了证明且证明方法会在习题中复用；证明较短（约 15 行以内）；教材标“请读者自证”的结论（必须补全） | 每一步写出并注明依据 |
| B：思路 + 关键步骤 | 教材给出了较长的证明（约半页以上） | 按“目标 → 关键构造/关键想法 → 关键等式或不等式 → 结论”写，必须点出用到的前置定理，并补出教材跳过的关键一步；末尾注明“完整证明见教材书页 X” |
| C：说明结论 | 教材未证明、引参考书的结论 | 写清结论与适用条件；若有简短的标准证明，可作为**拓展**给出 |

B 级不属于“省略”，但不能只写一句“利用某某定理即可证明”。

**推导证明只针对有编号的结论。** 上表的 A/B 级要求只适用于教材中带编号的定理、推论、引理（如定理 1.6-2）以及带编号的公式。教材中没有编号的结论（如未编号的推论、正文中的性质列举、“由此可知……”式的小结论）按教材原话转述即可，可以附一句理由，但不强制补证明；工具也不核对这类条目的覆盖，靠清单人工保证不漏讲。教材标“请读者自证”的**有编号**结论仍按 A 级补全。

#### 6.5.6 例子的来源与标注

- 教材正文例：标“（教材书页 N 正文例）”或“（教材 x.y 节例 N）”，**重新组织解答并补出步骤**。
- 自编：标“（自编）”；改编：标“（改编自教材 x.y 节例 N）”。数字设计应使手算可行（整数或简单分数优先），全部进入验算脚本。
- 不得把习题当例题讲（习题在习题导航中链接）；不得使用来源不明的数据。

### 6.6 方法与题型归纳

按“题型一、题型二……”组织，每个题型给出**步骤化**的方法（编号列表），每一步注明依据的教材编号或知识点 ID。第二部分的算法要写成可以照着手算的步骤（含初值、终止准则、每步计算公式）；第三部分的检验/估计要写成“提出假设 → 选统计量 → 确定分布与拒绝域（或区间）→ 计算 → 结论”的标准流程。

### 6.7 典型例题

- 每节 2–4 道（1 页的小节至少 1 道，工具对 1 道只给警告），标题格式 `### 例题 N　标题（来源）`。
- 至少 1 道为自编或改编。
- 每道题包含 `**题目**`、`**分析**`、`**解**`、`**答案**`、`**点评**`。数值题给出全部中间结果，迭代、递推、查表给出表格。
- 点评要说清“本题说明了什么、可推广到哪类题、容易错在哪里”。

### 6.8 易错点辨析

4–8 条，编号列表。每条：**一句话点明错误** → 错在哪里 → 正确做法 → 理由或反例，并注明对应知识点。来源优先级：教材的注释与反例 > 现有习题解答中的说明与勘误 > 公认的常见误解。

### 6.9 本节小结

一张速查表，列为 `结论 | 公式 | 条件 | 出处`。第二部分可改用 `方法 | 计算格式 | 收敛/精度条件 | 误差或阶 | 出处`；第三部分可改用 `场合 | 统计量 | 分布 | 拒绝域或区间 | 出处`。表格内公式不得出现 ASCII 竖线（§8）。

### 6.10 自测题与答案

3–8 道，题型混合（判断、填空、计算、简答），题号与答案一一对应。答案给结论 + 一两句理由，并注明对应知识点；计算题答案须验算。

### 6.11 习题导航

表格 `题目 | 考查知识点 | 解题要点`，覆盖分配给本节的**每一道**习题（工具核对“第 n 题”是否出现）；解题要点一句话。该题若有教材勘误或题目缺陷（见 README），在要点中提示。表格后一行链接到习题解答文件。

### 6.12 篇幅

以“去空白后字符数（含公式源码）”计，工具给出建议范围：下限 = 8000 + 2500 × 教材页数，上限 = 20000 + 6000 × 教材页数（样章 3 页约 2.2 万字符）。超出范围只给警告；**宁可紧凑准确，不要用套话凑篇幅**。篇幅分配：知识点讲解约 50%，题型与例题约 25%，其余约 25%。

### 6.13 写作风格

- 简体中文，书面而不艰涩；短句；一段只讲一件事。可用“我们”，不用“你”“同学们”。
- 每个概念都回答“是什么、为什么要它、怎么用、什么时候不能用”。
- 用反例说明条件的必要性；用对比说明相近概念的区别；用小例子落实抽象结论。
- 禁止空话套话（“非常重要”“大家一定要注意”“众所周知”）、感叹号堆砌、emoji。
- 对教材的评价要克制、有依据（“教材此处写作……严格说……”），不贬低教材。
- 不使用“本讲解认为”“笔者”等字样；不提及本工程的执行者或工具。

### 6.14 三个部分的侧重

| 部分 | 讲解侧重 | 典型例题要求 |
|---|---|---|
| 第一部分 矩阵论 | 概念辨析、定理条件与反例、证明技巧、标准计算流程（Jordan 形、各种分解、方阵函数） | 计算题给出完整的行列式展开、初等变换、求逆过程；证明题写出每步依据 |
| 第二部分 数值计算方法 | 构造思想 → 算法步骤 → 收敛性与误差（阶）→ 计算量 → 稳定性；不同方法的比较 | 迭代、递推、插值、求积给出逐步数值表；注明舍入位数；与精确解比较误差 |
| 第三部分 数理统计 | 统计思想、公式成立条件、标准步骤、查表（下侧分位数）、记号差异 | 给出查表值及附表出处（并用 scipy 复核）；检验题写清假设、统计量、拒绝域、结论 |

## 8. 数学排版规范

1. 行内公式 `$...$`，行间公式 `$$...$$`；行间公式必须独占行（可以在引用块中以 `> ` 开头）；行内公式不得跨行。
2. 禁止 `\(...\)`、`\[...\]`、`\begin{equation}`、`\begin{align}`、`\label`、`\eqref`、`\ref`。多行公式用 `$$\begin{aligned}...\end{aligned}$$`，分段函数用 `cases`，矩阵用 `bmatrix`，行列式用 `vmatrix`。
3. 只有重述带编号的教材公式时才用 `\tag{x.y-z}`；不得给自己写的公式编号（需要时用文字指代，如“上式”“(1) 式”在同一段内使用）。
4. 向量与矩阵用 `\boldsymbol`；转置 `^{\mathrm T}`，共轭转置 `^{\mathrm H}`；虚数单位 `\mathrm i`；自然常数 `\mathrm e`；微分 `\mathrm d x`；算子 `\mathrm{Sp}`、`\mathrm{Cond}`、`\operatorname{diag}`、`\operatorname{tr}` 等按教材记号选择。
5. 不等号用 `\leqslant`、`\geqslant`（与现有解答一致）。
6. **表格单元格内的公式不得出现 ASCII 竖线**：范数写 `\lVert x\rVert`，绝对值写 `\lvert x\rvert`，条件概率竖线写 `\mid`。表格外正常使用 `\|x\|`、`|x|`。
7. 中文与行内公式之间留一个半角空格（与现有解答一致），公式紧邻全角标点时不留空格；中文语境一律用全角标点。
8. 知识点块与例题中的加粗标签（教材依据、理解、要点、证明思路、例、易错、拓展、关联、题目、分析、解、答案、点评）后接全角空格，如 `**教材依据**　`；头部信息块与“本节导读”中的字段标签后接全角冒号，如 `**教材位置**：`、`**学习重点**：`。
9. 不使用 HTML 标签、HTML 注释、图片、代码块、emoji、脚注语法、Mermaid。
10. 标题中不放公式（知识点名称、例题标题都用文字）。
11. 数值：保留位数在同一张表内统一；近似值用 `\approx`；需要时注明“保留 4 位小数”。

## 9. 单节标准作业流程（SOP）

### 9.1 作业步骤

以节 `<ID>` 为例。每一步完成后再进入下一步，不要先写正文再补清单。

**第 0 步　准备**

1. `python3 .work/kp/tools/kp_tool.py pages <ID>`，得到阅读范围与图像路径。
2. 阅读本文件 §12 中本章的写作要点；阅读本章已完成的节讲解（保持记号与风格一致）；回顾样章。
3. 第二、三部分：确认本章习题分配表（§9.3）已存在；本章第一个任务包负责创建它。

**第 1 步　通读教材**

1. 按顺序读完 `read_pdf_pages` 范围内的**每一页**（含与上一节、下一节共用的页面的相应部分）。
2. 公式密集或看不清的页面用 300 dpi 重读，记入清单 `hires_pdf_pages`。
3. 为了引用而查看的其他页面（前置定义、被引公式、后续应用）也要实际打开，记入 `extra_pages_consulted`。

**第 2 步　建立清单 `.work/kp/inventory/<ID>.json`**（格式见 §9.2）

列出阅读范围内的全部定义、定理、推论、引理、性质、编号例题、正文无编号例子、编号公式、表、算法、注释，以及本节记号表、发现的印刷问题。这一步的目的有两个：保证不漏讲；为工具核对引用提供依据。

**第 3 步　对应习题**

1. 读对应的习题解答文件：每道题考什么、用了哪些教材编号、有无勘误或题目缺陷说明。
2. 把本节的习题写进清单 `exercises`（第一部分：该习题集的全部题；第二、三部分：分配到本节的题）。

**第 4 步　设计知识点**

确定知识点列表（ID 与名称）和知识结构；把清单每个条目的 `kp` 填好（或填 `skip_reason`）。

**第 5 步　写作**

按模板与样章写到 `sections.json` 指定的路径。所有链接用 `kp_tool.py link` 生成。

**第 6 步　验算**

写 `.work/kp/verify/<ID>.py`（§9.4），运行直到输出 `ALL OK`。验算发现与正文不符时，以验算为准修改正文，并复查推导。

**第 7 步　自检**

1. `python3 .work/kp/tools/kp_tool.py check <ID>`：错误必须清零；警告逐条判断，保留的警告在回报中说明理由。
2. **对照教材第二遍**：重新打开每一张页面图像，逐条核对讲解中的每个定义、定理陈述、编号、页码、记号。这一步不可省。
3. 逐条过一遍 §11.1 完成定义。

**第 8 步　记录**

更新 `PROGRESS.md`（状态、日期、备注）；把未解决问题登记 `ISSUES.md`。

### 9.2 清单格式（`inventory/<ID>.json`）

以 `inventory/M3.3.json` 为范例。字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | 字符串 | 节 ID |
| `title` | 字符串 | 节标题 |
| `read_book_pages` / `read_pdf_pages` | `[起, 止]` | 实际读过的范围（至少覆盖 `sections.json` 规定范围） |
| `hires_pdf_pages` | 数组 | 用 300 dpi 重读过的 PDF 页 |
| `extra_pages_consulted` | 数组 `{book_page, why}` | 为引用、核实而查看的其他页 |
| `notation` | 数组 `{symbol, latex, meaning, book_page}` | 本节记号表（`latex` 字段中的反斜杠要写成 `\\`） |
| `items` | 数组 `{type, no, book_page, summary, kp, skip_reason?, printed_as?}` | `type` 取：定义、定理、推论、引理、性质、例、正文例、式、表、图、算法、注；`no` 写编号（如 `3.3-1`；例题写 `1`；无编号写空串）；`kp` 写知识点 ID，确实不在讲解中体现的写 `skip_reason` |
| `errata` | 数组 `{book_page, text}` | 教材印刷错误或不严密之处 |
| `exercises` | 数组 `{set, no, kp[], method}` | 本节负责的习题 |
| `verify_script` | 字符串 | 验算脚本路径 |

规则：

- 阅读范围内**所有带编号**的定义、定理、推论、引理、例题、公式、表都要登记（公式编号也要全部登记，这是工具核对“式 (x.y-z)”引用的依据）。
- `summary` 用纯文本，数学符号用 Unicode（ρ、‖·‖、ᴴ 等），不写 LaTeX。
- 印刷错误的编号按更正后的编号登记，并加 `"printed_as": "教材印作的编号"`。

### 9.3 第二、三部分的习题分配表

第二、三部分每章只有一个习题集。在该章第一个任务包开始时，读完本章全部正文目录与全部习题，建立 `.work/kp/inventory/<章ID>_习题分配.md`（如 `N4_习题分配.md`），表格列为 `题号 | 主要考查内容 | 主属节 | 兼及节`。规则：

- 每道题必须有且只有一个主属节；综合题可列兼及节。
- 主属节的清单 `exercises` 必须包含该题；兼及节可以包含（工具对两者都会核对“习题导航”中是否出现）。
- 章检查（`check <章ID>`）会核对全部题都已分配。

### 9.4 验算脚本（`verify/<ID>.py`）

以 `verify/M3.3.py` 为范例：

- 只用 `numpy`、`scipy`、`sympy` 与标准库；脚本自包含、可重复运行。
- 对讲解中出现的每一个数值（含表格中每个数、自测题答案）写 `assert`，比较时容差与正文保留位数一致。
- 符号推导（如特征多项式、展开式）用 `sympy` 精确核对。
- 统计查表值用 `scipy.stats` 核对，并与教材附表值比较（附表与 scipy 不一致时，讲解用附表值并注明，登记 `ISSUES.md`）。
- 运行成功时最后一行打印 `ALL OK`。本节确实没有任何数值内容时，脚本也要存在，在文档字符串中说明原因并打印 `ALL OK`。

### 12.1 第一部分 矩阵论（书页 3–152）

**第1章 线性代数基本知识**（书页 3–49；6 节；习题 1.1–1.6 共 37 题）

- 【已核实】章首说明本章“带有复习性质”（书页 3）。讲解定位：梳理并突出后续各章要用的结论，不必写成本科教材的全部细节，篇幅可取建议范围的下部；但教材的每个定义、定理仍须覆盖。
- 【已核实】向量默认为列向量，$\boldsymbol x=[x_1,\cdots,x_n]^{\mathrm T}$（书页 3）；本章用 $|\boldsymbol\alpha|$ 表示向量长度、$\langle\boldsymbol\alpha,\boldsymbol\beta\rangle$ 表示内积，Cauchy-Schwarz 不等式为式 (1.1-2)，三角不等式为式 (1.1-3)（书页 5）。注意与第 3 章范数记号 $\|\boldsymbol x\|$ 的衔接。
- 【核查】1.3 节等价标准形与秩的记号（现有解答使用 $r(\boldsymbol A)$）；1.4 节解的存在定理的编号（现有解答有“定理 1.4.1”点号写法，以教材为准写成“定理 1.4-1”）。
- 【核查】1.5 节相似对角化的充要条件、Hermite 矩阵与实对称矩阵的性质编号。
- 【已核实（M1.6 编写时）】1.6 节（书页 43–49）的内容是：二次型的矩阵、合同（定义 1.6-1）、正交变换化标准形（定理 1.6-1）、正定与半正定（定义 1.6-2，定理 1.6-2、1.6-3、1.6-4 及其推论）。**教材本节没有讲配方法和惯性定理**，讲解中若提及只能作为“（教材未列）”的拓展。
- 已知勘误：习题 1.6 第 1 题“$4x_{12}$”应为 $4x_1x_2$（README）。

**第2章 方阵的相似化简**（书页 50–79；4 节；习题 2.1–2.4 共 19 题）

- 2.1 节是全书最难的节之一（12 页）。【已核实（据现有解答引用）】教材以“$k$ 级根向量”（定义 2.1-2，式 (2.1-11)）为主线，并在书页 61 给出由代数重数、几何重数、指标确定 Jordan 结构的结论。【核查】教材是否另讲 λ-矩阵或初等因子法；讲解以教材路线为主线，其他方法最多作为拓展。
