# 习题 4.1 解答

## 题目来源
《高等工程数学》第4版 第95页

## 1. 求矩阵 $A=\begin{bmatrix}1+i & 3\\2 & 1-i\end{bmatrix}$ 的谱半径 $\rho(A)$。

**解：**

谱半径定义为 $\rho(A) = \max\limits_{1\leq i\leq n}|\lambda_i|$，需要先求矩阵 $A$ 的特征值。

计算特征多项式：
$$\det(A-\lambda I) = \begin{vmatrix}1+i-\lambda & 3\\2 & 1-i-\lambda\end{vmatrix}$$

$$= (1+i-\lambda)(1-i-\lambda) - 6$$

$$= (1-\lambda)^2 - i^2 - 6$$

$$= 1 - 2\lambda + \lambda^2 + 1 - 6$$

$$= \lambda^2 - 2\lambda - 4$$

解特征方程 $\lambda^2 - 2\lambda - 4 = 0$：

$$\lambda = \frac{2 \pm \sqrt{4+16}}{2} = \frac{2 \pm \sqrt{20}}{2} = 1 \pm \sqrt{5}$$

因此特征值为：
- $\lambda_1 = 1 + \sqrt{5} \approx 3.236$
- $\lambda_2 = 1 - \sqrt{5} \approx -1.236$

谱半径：
$$\rho(A) = \max\{|1+\sqrt{5}|, |1-\sqrt{5}|\} = 1 + \sqrt{5}$$

**答案：** $\rho(A) = 1 + \sqrt{5}$

## 2. 证明，若 $A$ 是正规矩阵，则 $\rho(A) = \|A\|_2$。

**证明：**

设 $A$ 是 $n$ 阶正规矩阵，即 $A^HA = AA^H$。

由正规矩阵的性质，存在酉矩阵 $U$ 使得：
$$A = U\Lambda U^H$$

其中 $\Lambda = \text{diag}(\lambda_1, \lambda_2, \cdots, \lambda_n)$ 是 $A$ 的特征值组成的对角矩阵。

计算 $A$ 的2-范数：
$$\|A\|_2 = \sqrt{\lambda_{\max}(A^HA)}$$

因为 $A = U\Lambda U^H$，所以：
$$A^HA = (U\Lambda U^H)^H(U\Lambda U^H) = U\Lambda^H U^H U\Lambda U^H = U\Lambda^H\Lambda U^H$$

$$= U\text{diag}(|\lambda_1|^2, |\lambda_2|^2, \cdots, |\lambda_n|^2)U^H$$

因此：
$$\lambda_{\max}(A^HA) = \max\{|\lambda_1|^2, |\lambda_2|^2, \cdots, |\lambda_n|^2\} = [\max\{|\lambda_1|, |\lambda_2|, \cdots, |\lambda_n|\}]^2 = [\rho(A)]^2$$

所以：
$$\|A\|_2 = \sqrt{[\rho(A)]^2} = \rho(A)$$

证毕。

## 3. 设 $n$ 阶方阵 $A$ 使得 $\|A\|_\infty \leq \max\limits_{1\leq i\leq n}\sum\limits_{j=1}^{n}|a_{ij}|$。证明 $\rho(A) \leq \max\limits_{2\leq i\leq n}|a_i|$。

**注：** 题目表述可能有误，根据矩阵范数理论，应证明 $\rho(A) \leq \|A\|$ 对任意矩阵范数成立。

**证明：**

设 $\lambda$ 是 $A$ 的任一特征值，$x$ 是对应的特征向量，$\|x\| = 1$（在某范数下）。

则：
$$Ax = \lambda x$$

两边取范数：
$$|\lambda| \cdot \|x\| = \|\lambda x\| = \|Ax\| \leq \|A\| \cdot \|x\|$$

因为 $\|x\| = 1$，所以：
$$|\lambda| \leq \|A\|$$

对所有特征值成立，因此：
$$\rho(A) = \max\limits_i |\lambda_i| \leq \|A\|$$

特别地，对于 $\infty$-范数：
$$\|A\|_\infty = \max\limits_{1\leq i\leq n}\sum\limits_{j=1}^{n}|a_{ij}|$$

因此：
$$\rho(A) \leq \|A\|_\infty = \max\limits_{1\leq i\leq n}\sum\limits_{j=1}^{n}|a_{ij}|$$

证毕。
