# 习题3.1 解答

## 第1题

**题目：** 在 $\mathbb{R}^3$ 中，将向量 $\mathbf{x} = [x_1, x_2, x_3]^T$ 看成是平面上直角坐标系下的点 $(x_1, x_2)$，分别画出下列不等式所确定的几何区域的边界：

$$\|\mathbf{x}\|_1 \leq 1, \quad \|\mathbf{x}\|_2 \leq 1, \quad \|\mathbf{x}\|_\infty \leq 1$$

### 解题思路
理解三种常见范数的几何意义：
- 1-范数：$\|\mathbf{x}\|_1 = |x_1| + |x_2|$（菱形）
- 2-范数：$\|\mathbf{x}\|_2 = \sqrt{x_1^2 + x_2^2}$（圆）
- $\infty$-范数：$\|\mathbf{x}\|_\infty = \max\{|x_1|, |x_2|\}$（正方形）

### 详细解答

**（1）1-范数的单位球：** $\|\mathbf{x}\|_1 = |x_1| + |x_2| \leq 1$

边界方程：$|x_1| + |x_2| = 1$

这是一个菱形，顶点为：$(1, 0)$, $(0, 1)$, $(-1, 0)$, $(0, -1)$

在第一象限：$x_1 + x_2 = 1$
在第二象限：$-x_1 + x_2 = 1$
在第三象限：$-x_1 - x_2 = 1$
在第四象限：$x_1 - x_2 = 1$

**（2）2-范数的单位球：** $\|\mathbf{x}\|_2 = \sqrt{x_1^2 + x_2^2} \leq 1$

边界方程：$x_1^2 + x_2^2 = 1$

这是以原点为中心、半径为 1 的圆。

**（3）$\infty$-范数的单位球：** $\|\mathbf{x}\|_\infty = \max\{|x_1|, |x_2|\} \leq 1$

边界方程：$\max\{|x_1|, |x_2|\} = 1$

这等价于：$|x_1| \leq 1$ 且 $|x_2| \leq 1$

边界是正方形，顶点为：$(1, 1)$, $(-1, 1)$, $(-1, -1)$, $(1, -1)$

### 答案

三种范数的单位球边界：
- **1-范数**：菱形，顶点 $(\pm 1, 0)$ 和 $(0, \pm 1)$
- **2-范数**：单位圆 $x_1^2 + x_2^2 = 1$
- **$\infty$-范数**：正方形，边界 $|x_1| = 1$ 或 $|x_2| = 1$

## 第2题

**题目：** 设 $\|\cdot\|_a$ 与 $\|\cdot\|_b$ 是 $\mathbb{C}^n$ 上的两种向量范数，$k_1, k_2$ 是正实数，证明下列范数都是向量范数：

(1) $\max\{\|\mathbf{x}\|_a, \|\mathbf{x}\|_b\}$  
(2) $k_1\|\mathbf{x}\|_a + k_2\|\mathbf{x}\|_b$

### 解题思路
验证向量范数的三个公理：
1. 正定性：$\|\mathbf{x}\| \geq 0$，且 $\|\mathbf{x}\| = 0 \Leftrightarrow \mathbf{x} = \mathbf{0}$
2. 齐次性：$\|\lambda\mathbf{x}\| = |\lambda| \|\mathbf{x}\|$
3. 三角不等式：$\|\mathbf{x} + \mathbf{y}\| \leq \|\mathbf{x}\| + \|\mathbf{y}\|$

### 详细解答

**证明 (1)：** 设 $\|\mathbf{x}\|_{\max} = \max\{\|\mathbf{x}\|_a, \|\mathbf{x}\|_b\}$

**正定性：**
- 因为 $\|\mathbf{x}\|_a \geq 0$ 且 $\|\mathbf{x}\|_b \geq 0$，所以 $\|\mathbf{x}\|_{\max} \geq 0$
- 若 $\mathbf{x} = \mathbf{0}$，则 $\|\mathbf{0}\|_a = \|\mathbf{0}\|_b = 0$，故 $\|\mathbf{0}\|_{\max} = 0$
- 若 $\|\mathbf{x}\|_{\max} = 0$，则 $\max\{\|\mathbf{x}\|_a, \|\mathbf{x}\|_b\} = 0$，因此 $\|\mathbf{x}\|_a = \|\mathbf{x}\|_b = 0$，由正定性得 $\mathbf{x} = \mathbf{0}$

**齐次性：**
$$\|\lambda\mathbf{x}\|_{\max} = \max\{\|\lambda\mathbf{x}\|_a, \|\lambda\mathbf{x}\|_b\}$$
$$= \max\{|\lambda|\|\mathbf{x}\|_a, |\lambda|\|\mathbf{x}\|_b\}$$
$$= |\lambda| \max\{\|\mathbf{x}\|_a, \|\mathbf{x}\|_b\} = |\lambda| \|\mathbf{x}\|_{\max}$$

**三角不等式：**
$$\|\mathbf{x} + \mathbf{y}\|_{\max} = \max\{\|\mathbf{x} + \mathbf{y}\|_a, \|\mathbf{x} + \mathbf{y}\|_b\}$$
$$\leq \max\{\|\mathbf{x}\|_a + \|\mathbf{y}\|_a, \|\mathbf{x}\|_b + \|\mathbf{y}\|_b\}$$
$$\leq \max\{\|\mathbf{x}\|_a, \|\mathbf{x}\|_b\} + \max\{\|\mathbf{y}\|_a, \|\mathbf{y}\|_b\}$$
$$= \|\mathbf{x}\|_{\max} + \|\mathbf{y}\|_{\max}$$

**证明 (2)：** 设 $\|\mathbf{x}\|_c = k_1\|\mathbf{x}\|_a + k_2\|\mathbf{x}\|_b$，其中 $k_1, k_2 > 0$

**正定性：**
- $\|\mathbf{x}\|_c = k_1\|\mathbf{x}\|_a + k_2\|\mathbf{x}\|_b \geq 0$（因为 $k_1, k_2 > 0$ 且范数非负）
- 若 $\mathbf{x} = \mathbf{0}$，则 $\|\mathbf{0}\|_c = k_1 \cdot 0 + k_2 \cdot 0 = 0$
- 若 $\|\mathbf{x}\|_c = 0$，则 $k_1\|\mathbf{x}\|_a + k_2\|\mathbf{x}\|_b = 0$。由于各项非负，得 $\|\mathbf{x}\|_a = \|\mathbf{x}\|_b = 0$，故 $\mathbf{x} = \mathbf{0}$

**齐次性：**
$$\|\lambda\mathbf{x}\|_c = k_1\|\lambda\mathbf{x}\|_a + k_2\|\lambda\mathbf{x}\|_b$$
$$= k_1|\lambda|\|\mathbf{x}\|_a + k_2|\lambda|\|\mathbf{x}\|_b$$
$$= |\lambda|(k_1\|\mathbf{x}\|_a + k_2\|\mathbf{x}\|_b) = |\lambda|\|\mathbf{x}\|_c$$

**三角不等式：**
$$\|\mathbf{x} + \mathbf{y}\|_c = k_1\|\mathbf{x} + \mathbf{y}\|_a + k_2\|\mathbf{x} + \mathbf{y}\|_b$$
$$\leq k_1(\|\mathbf{x}\|_a + \|\mathbf{y}\|_a) + k_2(\|\mathbf{x}\|_b + \|\mathbf{y}\|_b)$$
$$= (k_1\|\mathbf{x}\|_a + k_2\|\mathbf{x}\|_b) + (k_1\|\mathbf{y}\|_a + k_2\|\mathbf{y}\|_b)$$
$$= \|\mathbf{x}\|_c + \|\mathbf{y}\|_c$$

**证毕。**

## 第3题

**题目：** 设 $m \times n$ 复矩阵 $A$ 是列满秩的，$\varphi(\cdot)$ 是 $\mathbb{C}^m$ 上的向量范数，证明由 $\varphi(A\mathbf{x})$ 所确定的函数是 $\mathbb{R}^n$ 的向量范数。若 $A$ 不是列满秩的，$\varphi(A\mathbf{x})$ 是 $\mathbf{x}$ 的向量范数吗？

### 解题思路
需要验证 $\|\mathbf{x}\|_A = \varphi(A\mathbf{x})$ 满足范数的三个公理。关键是正定性，这依赖于 $A$ 的列满秩性质。

### 详细解答

**证明：** 设 $\|\mathbf{x}\|_A = \varphi(A\mathbf{x})$，其中 $A \in \mathbb{C}^{m \times n}$ 列满秩，$\varphi$ 是 $\mathbb{C}^m$ 上的向量范数。

**正定性：**
- 非负性：$\|\mathbf{x}\|_A = \varphi(A\mathbf{x}) \geq 0$（因为 $\varphi$ 是范数）
- 若 $\mathbf{x} = \mathbf{0}$，则 $\|\mathbf{0}\|_A = \varphi(A\mathbf{0}) = \varphi(\mathbf{0}) = 0$
- 若 $\|\mathbf{x}\|_A = 0$，则 $\varphi(A\mathbf{x}) = 0$。由 $\varphi$ 的正定性，$A\mathbf{x} = \mathbf{0}$。因为 $A$ 列满秩，$\text{rank}(A) = n$，所以 $\ker(A) = \{\mathbf{0}\}$，因此 $\mathbf{x} = \mathbf{0}$

**齐次性：**
$$\|\lambda\mathbf{x}\|_A = \varphi(A(\lambda\mathbf{x})) = \varphi(\lambda A\mathbf{x}) = |\lambda| \varphi(A\mathbf{x}) = |\lambda| \|\mathbf{x}\|_A$$

**三角不等式：**
$$\|\mathbf{x} + \mathbf{y}\|_A = \varphi(A(\mathbf{x} + \mathbf{y})) = \varphi(A\mathbf{x} + A\mathbf{y})$$
$$\leq \varphi(A\mathbf{x}) + \varphi(A\mathbf{y}) = \|\mathbf{x}\|_A + \|\mathbf{y}\|_A$$

因此 $\|\mathbf{x}\|_A$ 是 $\mathbb{C}^n$ 上的向量范数。

**若 $A$ 不是列满秩：**

如果 $\text{rank}(A) < n$，则 $\ker(A) \neq \{\mathbf{0}\}$，存在非零向量 $\mathbf{x}_0 \neq \mathbf{0}$ 使得 $A\mathbf{x}_0 = \mathbf{0}$。

此时：
$$\|\mathbf{x}_0\|_A = \varphi(A\mathbf{x}_0) = \varphi(\mathbf{0}) = 0$$

但 $\mathbf{x}_0 \neq \mathbf{0}$，这违反了正定性。因此 $\varphi(A\mathbf{x})$ **不是**向量范数。

### 答案

- 当 $A$ 列满秩时，$\varphi(A\mathbf{x})$ 是 $\mathbb{C}^n$ 上的向量范数
- 当 $A$ 不是列满秩时，$\varphi(A\mathbf{x})$ 不是向量范数（正定性不满足）

## 第4题

**题目：** 证明：对任意 $\mathbf{x} \in \mathbb{C}^n$，有

(1) $\|\mathbf{x}\|_\infty \leq \|\mathbf{x}\|_1 \leq n\|\mathbf{x}\|_\infty$  
(2) $\|\mathbf{x}\|_\infty \leq \|\mathbf{x}\|_2 \leq \sqrt{n}\|\mathbf{x}\|_\infty$  
(3) $\displaystyle\frac{\|\mathbf{x}\|_2}{\sqrt{n}} \leq \|\mathbf{x}\|_1 \leq \sqrt{n}\|\mathbf{x}\|_2$

### 解题思路
利用向量分量的性质和不等式关系，特别是Cauchy-Schwarz不等式。

### 详细解答

**证明 (1)：** $\|\mathbf{x}\|_\infty \leq \|\mathbf{x}\|_1 \leq n\|\mathbf{x}\|_\infty$

设 $\mathbf{x} = [x_1, x_2, \ldots, x_n]^T$。

**左边不等式：** $\|\mathbf{x}\|_\infty \leq \|\mathbf{x}\|_1$

$$\|\mathbf{x}\|_\infty = \max_{1 \leq i \leq n} |x_i| = |x_k|$$（某个 $k$）

$$\|\mathbf{x}\|_1 = \sum_{i=1}^n |x_i| \geq |x_k| = \|\mathbf{x}\|_\infty$$

**右边不等式：** $\|\mathbf{x}\|_1 \leq n\|\mathbf{x}\|_\infty$

$$\|\mathbf{x}\|_1 = \sum_{i=1}^n |x_i| \leq \sum_{i=1}^n \max_{1 \leq j \leq n} |x_j| = n \|\mathbf{x}\|_\infty$$

**证明 (2)：** $\|\mathbf{x}\|_\infty \leq \|\mathbf{x}\|_2 \leq \sqrt{n}\|\mathbf{x}\|_\infty$

**左边不等式：** $\|\mathbf{x}\|_\infty \leq \|\mathbf{x}\|_2$

$$\|\mathbf{x}\|_2^2 = \sum_{i=1}^n |x_i|^2 \geq \max_{1 \leq i \leq n} |x_i|^2 = \|\mathbf{x}\|_\infty^2$$

因此 $\|\mathbf{x}\|_2 \geq \|\mathbf{x}\|_\infty$

**右边不等式：** $\|\mathbf{x}\|_2 \leq \sqrt{n}\|\mathbf{x}\|_\infty$

$$\|\mathbf{x}\|_2^2 = \sum_{i=1}^n |x_i|^2 \leq \sum_{i=1}^n \|\mathbf{x}\|_\infty^2 = n\|\mathbf{x}\|_\infty^2$$

因此 $\|\mathbf{x}\|_2 \leq \sqrt{n}\|\mathbf{x}\|_\infty$

**证明 (3)：** $\displaystyle\frac{\|\mathbf{x}\|_2}{\sqrt{n}} \leq \|\mathbf{x}\|_1 \leq \sqrt{n}\|\mathbf{x}\|_2$

**右边不等式：** $\|\mathbf{x}\|_1 \leq \sqrt{n}\|\mathbf{x}\|_2$（Cauchy-Schwarz不等式）

$$\|\mathbf{x}\|_1 = \sum_{i=1}^n |x_i| = \sum_{i=1}^n 1 \cdot |x_i| \leq \sqrt{\sum_{i=1}^n 1^2} \cdot \sqrt{\sum_{i=1}^n |x_i|^2} = \sqrt{n} \|\mathbf{x}\|_2$$

**左边不等式：** $\displaystyle\frac{\|\mathbf{x}\|_2}{\sqrt{n}} \leq \|\mathbf{x}\|_1$

由Cauchy-Schwarz不等式的反向形式：

$$\|\mathbf{x}\|_2^2 = \sum_{i=1}^n |x_i|^2 \leq \left(\sum_{i=1}^n |x_i|\right)^2 / n \cdot n = \|\mathbf{x}\|_1^2$$

等等，这个不对。正确的做法：

$$\|\mathbf{x}\|_1^2 = \left(\sum_{i=1}^n |x_i|\right)^2 = \left(\sum_{i=1}^n 1 \cdot |x_i|\right)^2$$

由Cauchy-Schwarz不等式：
$$\left(\sum_{i=1}^n 1 \cdot |x_i|\right)^2 \leq \left(\sum_{i=1}^n 1^2\right)\left(\sum_{i=1}^n |x_i|^2\right) = n\|\mathbf{x}\|_2^2$$

因此 $\|\mathbf{x}\|_1 \leq \sqrt{n}\|\mathbf{x}\|_2$（这是右边不等式）

对于左边不等式，我们可以直接从 $\|\mathbf{x}\|_1^2$ 出发：

$$\|\mathbf{x}\|_1^2 \geq \frac{1}{n}\left(\sum_{i=1}^n |x_i|\right)^2 \cdot n$$

实际上，从另一个角度：

$$n\|\mathbf{x}\|_2^2 = n\sum_{i=1}^n |x_i|^2 \geq \left(\sum_{i=1}^n |x_i|\right)^2 = \|\mathbf{x}\|_1^2$$

（这里用到：对于非负数，调和平均 ≤ 算术平均 ≤ 平方平均）

因此 $\|\mathbf{x}\|_1 \leq \sqrt{n}\|\mathbf{x}\|_2$，即 $\displaystyle\frac{\|\mathbf{x}\|_1}{\sqrt{n}} \leq \|\mathbf{x}\|_2$

反过来就是 $\displaystyle\frac{\|\mathbf{x}\|_2}{\sqrt{n}} \leq \|\mathbf{x}\|_1$

**证毕。**

### 答案

三组不等式都成立，它们刻画了不同范数之间的等价关系，等价常数分别为 $n$、$\sqrt{n}$ 和 $\sqrt{n}$。
