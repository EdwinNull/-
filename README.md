# 《高等工程数学》（第 4 版）习题解答

> 于寅 编，2012 年

本解答集覆盖全书**三大部分、17 章、33 个习题集、252 道题**，逐题给出完整解答。

## 📐 编制说明

- **题源**：全部题目逐字取自教材扫描页图像（PDF 共 459 页，**PDF 页 = 书页 + 11**），未凭记忆自拟或改写任何题目与数据。
- **验算**：所有数值结果均用 `sympy` / `numpy` / `scipy` 独立复算核对；迭代法、数值积分、样条插值等题给出逐步迭代表格与中间数值。
- **规范**：每题含「题目 / 解 / 答案」三段；不使用「略」「读者自证」等省略表述；引用教材原编号的定理与公式（如「由定理 1.4.1」「由式 (5.3-4)」）。
- **存疑处理**：发现教材印刷问题时，在解答中以 `> **教材勘误**` 明确标注，并同时给出按正确题意的结果。

## 教材勘误汇总

解答过程中发现的教材印刷问题（均已在对应文件中标注）：

| 位置 | 问题 | 处理 |
|---|---|---|
| 习题 7（数值）第 1 题 | 题给「准确解 $y(x)=e^{-x}+x^2-x+1$」与初值 $y(0)=0$ 不相容（该函数 $y(0)=2$） | 按正确解 $y=x^2-x+1-e^{-x}$ 比较 |
| 习题 7（数值）第 4 题 | 线性多步法 $y_{i+1}=a(y_i-y_{i-1})+y_{i-2}+bh(y'_i+y'_{i-2})$ 的精度条件 $a+2b=3$、$a+4b=3$、$a+12b=9$ 不相容，不存在 4 阶解 | 按通常考法将导数项修正为 $y'_{i+1}+y'_{i-2}$，得 $a=\frac{27}{13}$、$b=\frac{6}{13}$ |
| 习题 4（数值）第 1 题(2) | 题面等价形式 $x=\sqrt[3]{1+x^2}$ 与所印迭代算式 $x^{(k+1)}=\sqrt[3]{1+1/[x^{(k)}]^2}$ 不一致：后者的不动点满足 $x^5-x^2-1=0$（根 $1.1938591$），不是本题的根 $1.4655712$ | 按等价形式 $x=\sqrt[3]{1+x^2}$ 判定收敛性（$\lvert\varphi'\rvert=0.4549<1$，收敛） |
| 习题 6.1 第 4 题 | $V_1=\mathrm{Span}(\boldsymbol\alpha_1,2\boldsymbol\alpha+\boldsymbol\alpha_2)$ 中 $\boldsymbol\alpha$ 漏印下标 | 按 $2\boldsymbol\alpha_1+\boldsymbol\alpha_2$ 求解 |
| 习题 6.3 第 5 题(1) | 印作 $(V_1+V_1)^{\perp}=V_1^{\perp}\cap V_2^{\perp}$，左端第二个 $V_1$ 应为 $V_2$（否则两端不对称、命题不成立） | 按 $(V_1+V_2)^{\perp}=V_1^{\perp}\cap V_2^{\perp}$ 求解 |
| 习题 6.2 第 10 题 | $f(\mathscr T)$ 定义末项印刷为 $a_0\mathscr T$ | 按数学含义应为 $a_0\mathscr I$ |
| 习题 1.6 第 1 题 | 第四项印作 $4x_{12}$（下标「12」），应为交叉项 $4x_1x_2$ | 按 $4x_1x_2$ 求解 |
| 习题 1（数值）第 1 题 | 印作 $b=-0.12341\times10^{2}$（五位数字），却称各近似值「均有四位有效数字」，题面自相矛盾 | 按四位有效数字取 $\varepsilon_b=0.5\times10^{-2}$，并注明若按五位则为 $0.5\times10^{-3}$ |
| 习题 1（统计）第 15 题 | 印作 $S_n^2=\frac1n\sum(X_i-\bar X_n)^2$（分母 $n$），而所给 $T=\sqrt{\frac{n}{n+1}}\,\frac{X_{n+1}-\bar X_n}{S_n}$ 仅当 $S_n$ 取分母 $n-1$ 时才服从 $t(n-1)$ | 按分母 $n-1$ 证明，并给出分母 $n$ 时的正确形式 $\sqrt{\frac{n-1}{n+1}}\,\frac{X_{n+1}-\bar X_n}{S_n}$ |
| 习题 3（统计）第 7 题 | 题面「$X\sim N(\mu;\sigma_1^2)$」应为 $N(\mu_1;\sigma_1^2)$ | 按 $N(\mu_1;\sigma_1^2)$ 求解 |
| 附表 $F$ 分布表 $p=0.95$（书页 438） | $n=10$ 行、$m=10$ 列印作 $2.48$，应为 $2.98$（$F_{0.95}(10,10)=2.978$，与同行左右邻值及 scipy 一致） | 与本书习题无直接关系，仅提示 |

### 题目本身的缺陷（非印刷问题，已如实指出）

| 位置 | 问题 |
|---|---|
| 习题 4（数值）第 9、10 题 | 目标函数 $F=4x_1^2+x_2^2-x_1^2x_2$ 从 $\boldsymbol{x}^{(0)}=[0,2]^{\mathrm T}$ 出发，三种方法第一次迭代都精确落到 $[0,0]^{\mathrm T}$（梯度为零），第二次迭代不动，故「迭代二次」结果仍是 $[0,0]^{\mathrm T}$。又因 $F=x_1^2(4-x_2)+x_2^2$ 在 $x_2>4$ 时**无下界**（如 $F(100,9)=-49919$），$[0,0]^{\mathrm T}$ 只是**局部**极小点，题目无全局最优解。解答中已明确说明。 |
| 习题 5（数值）第 16 题 | 模型 $y=ax^b$ 须先取对数线性化；末点 $x=7.9$ 处拟合偏差较大（残差 $-16.1$）。解答给出最小二乘解与完整残差表供判断。 |
| 习题 3（数值）第 1 题 | 仅凭 Gerschgorin 圆盘无法判定三个特征值是否全为实数（两圆盘相交）。解答补充相似变换 $P=\operatorname{diag}(3,4,2\sqrt{10})$ 使三圆两两分离以严格证明，并用三次多项式判别式独立佐证。 |

此外，若干题目存在**题意歧义或数值约定**问题（如几何分布参数化约定、Pareto 分布的边界 MLE、SOR 先验估计中矩阵范数须与向量范数配对使用、教材未列 $p<0.5$ 的 $F$ 分位数等），解答中均已逐处说明处理依据。
